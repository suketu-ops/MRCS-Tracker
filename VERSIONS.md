| 2026-08-19   | `v120.0`  | v119 + offline (service worker) | The Tracker now opens and drills **fully offline** — cold start in airplane mode works. | 2026-08-01   | `v119.0`  | v118 + drill intelligence layer | Audit found the in-app drill was a good question *delivery* surface but not a revision *system* — nothing it learned survived the session. Nine fixes. (1) **Objective grading**: `reclearReveal()` always computed picked-vs-correct and drew the tick/cross, then discarded it and asked you to self-grade *after* reading the answer. The pick now decides; self-grade buttons replaced by a verdict banner plus a deliberate "↺ Misclick — I knew this" override. (2) **Persistent per-question history** (`DRILL_HISTORY`, localStorage key `mrcs-drill-history`) keyed by cloud `qhash` or a djb2 of the stem: seen/right/wrong/streak/confidence. (3) **Weakest-first ordering** — was a blind Fisher-Yates over the whole pool every run. Bands: failed-last-time → never-seen → cleared-once → increasingly settled, shuffled within band. Failed deliberately leads unseen, per the revision plan's "re-clear your own failures first". (4) **Drill now feeds the SRS** — a fail creates a real `REVIEW_BANK` card (due now, `srsState:'learning'`, notes = correct answer + explanation, `errorType` `know` if confident / `retrieval` if hesitant, capped 30/session). The drill previously never touched the 731-card deck at all. (5) A correct answer flagged *hesitant* is held at streak 1 (a guess, not knowledge) and makes no card. (6) **CSC purge 547 → 476**: 71 questions across 42 topics were Paper 1 basic science mis-flagged `is_csc` ("Potassium secretion – GI tract", "Small Bowel Regional Anatomy"). Curated by hand, not regex — a regex on `cell ` swallows "Renal Cell Carcinoma", which is genuinely CSC. Applied client-side so a stale IndexedDB bank copy can't reintroduce them; `is_csc` also corrected in Supabase. (7) **Two dead topic chips fixed** — the list held `'AAA'` and `'BPH'` but the bank stores "Abdominal Aortic Aneurysm" / "Benign Prostatic Hyperplasia", so both matched zero questions despite being top-15 fail topics; now 8 and 5. (8) Four `…`-prefixed chips added to reach the **97 questions** that were filter-invisible behind catch-all labels ("General surgery" 42, etc.). (9) **Six scopes** (was `csc`\|`all`): CSC 476 · PoSG 875 · Periop 248 · Trauma 151 · **My QBank fails 1517** · All 2367. The "mine" scope filters on provenance (`source` ∈ eMRCS/Pastest) — `your_answer` is empty on all 2367 rows, so this was the only way to isolate his own logged failures from the mock-paper questions merged into the same bank. Cloud and offline-fallback paths verified to return identical counts. |

## Release ritual (going forward — one live file, no clutter)
1. Build/validate the new single file (jscheck PASS, headless boot 0 errors).
2. Copy it over `index.html`.
3. `git add -A && git commit -m "vX.Y: <summary>" && git tag vX.Y && git push --tags origin main`
4. Add a row here. No new `vNNN.html` file in the repo.
